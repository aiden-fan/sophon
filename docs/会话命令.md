# 会话级能力配置与 `/` 命令

<a id="toc-session-slash"></a>

## 设计目标

- **全局能力注册表**（进程内）：`ToolRegistry`、`SkillRegistry`、知识库清单仍由配置与加载器维护，表示「系统里有哪些」。
- **会话级启用集**：每个会话持久化一份 **本会话当前允许使用的** Tool、Skill、知识库子集；用户可在不同会话中使用不同组合（例如一个会话只开文档库与只读工具，另一个会话全开）。
- **生效点**：`ToolExecutor` / 暴露给 LLM 的 function 列表、`SkillExecutor` 可调用清单、`RAGEngine` / `KnowledgeManager` 的默认检索范围，均按**当前会话**配置过滤；若 Skill 声明依赖某 Tool 但该 Tool 在本会话被禁用，调用前应**拒绝并提示**。

## SessionCapabilityConfig（建议字段）

实现上可能与下列命名略有出入，以 `SessionCapabilityConfig` 源码为准；语义应对齐。

| 字段 / 概念                     | 说明                                                       |
| --------------------------- | -------------------------------------------------------- |
| `enabledToolIds`            | 允许调用的工具 id 集合；空可与「继承全局默认」或「全部关闭」二选一，需在实现中明确语义            |
| `enabledSkillIds`           | 允许用户显式调用的技能 id 集合（或 `/skill` 可见列表）                       |
| `enabledKnowledgeBaseNames` | 本会话 RAG / 检索可使用的知识库名称集合；可与「默认主库 + 附加库」组合                 |
| `citationsEnabled`          | 是否在 RAG 回答中展示引用列表（与 `/citations` 一致）                     |
| `trustLevel`                | 会话信任级别（如 `standard` / `elevated`），用于是否允许**高危 Tool**免确认执行 |
| `activeProfileId`           | 当前应用的**能力预设** id（若有）                                     |
| `inheritGlobalDefaults`     | 为 true 时，未单独覆盖的类别沿用全局默认启用策略                              |
| `systemPrompt`（或等价名）   | **本会话**发往模型的 **system** 文本；空表示不覆盖全局 `sophon.ai.system-prompt`；与 CLI `/prompt`、Web `PATCH` 同一语义 |
| `updatedAt`                 | 最后修改时间（用于展示）                                             |

新建会话时：从全局默认复制一份配置，或 `inheritGlobalDefaults=true` 且延迟求值，**文档与代码需一致**。

## `/` 命令约定（CLI）

- 用户输入**以 `/` 开头且匹配会话命令语法**的行时，**不**作为用户消息写入对话历史、**不**调用 LLM；由 `SlashCommandRouter` 解析并调用 `core/application` 中服务更新 `Session`，再输出文本反馈。
- 命令名大小写：建议 **一律小写**（如 `/tools`），子命令与 id 区分大小写策略与全局 id 规范一致（通常 id 小写）。

**建议命令集（可实现子集起步）：**

| 命令                                                               | 作用                                                    |
| ---------------------------------------------------------------- | ----------------------------------------------------- |
| `/help`                                                          | 列出支持的 `/` 命令                                          |
| `/session` 或 `/session show`                                     | 打印当前会话 id、模型（若有会话级覆盖）、能力开关摘要                          |
| `/prompt`、`/prompt show`                                         | 查看**本会话**当前生效的 system 提示（含全局默认与覆盖关系） |
| `/prompt set <文本>`                                              | **绑定到当前会话**：设置本会话 system 提示覆盖（单行） |
| `/prompt clear` / `/prompt reset`                                 | 清除本会话覆盖，恢复为全局默认 |
| `/tools`                                                         | 列出当前会话**已启用**的 Tool                                   |
| `/tools all`                                                     | 列出全局已注册 Tool 及本会话是否启用                                 |
| `/tools enable <id>` / `disable` / `reset`                        | 本会话启用/禁用/恢复 Tool                                          |
| `/skills` …                                                      | 同 Tool 语义，作用于 Skill                                        |
| `/kb` 或 `/knowledge` / `attach` / `detach` / `reset`             | 本会话知识库绑定                                             |
| `/citations on` / `off`                                            | 本会话是否展示 RAG **引用**                                    |
| `/profile list` / `save` / `apply` / `delete`                     | 能力预设 Profile                               |
| `/doctor`                                                        | **环境自检**                  |
| `/export json` / `/import json <path>` / `/fork`                  | 导出导入、分叉（以实现为准） |
| `/search <关键词>` / `/regenerate`                                | 历史检索、重答（以实现为准） |

**解析注意**：**首版推荐**：严格白名单子命令，未识别则提示「未知命令，输入 `/help`」。

## 与 Web 对齐

- Web 端以 **REST / JSON** 更新同一份 `SessionCapabilityConfig`（如 `PATCH /sessions/{id}/capabilities`），与 CLI 的 `/` 命令**共用** application 层 API。
- **聊天流式**：**SSE** 或 WebSocket，与 `AIProvider` 流式及 CLI 流式消费**同一用例**。
- **文档入知识库**：上传至指定 KB 的 API（权限、配额、扫描与 CLI 行为一致）。
- **导出/导入、用量查询、自检、Profile** 等均应有对应 HTTP 端点，**不得**仅在 CLI 实现。

## 实现挂钩

- `SlashCommandRouter` → `SessionCapabilityService`（位于 `core/application`）→ `SessionManager` 持久化。
- `AgentEngine` 构造每次请求的工具列表时注入 **当前会话的过滤视图**（可对 `ToolRegistry` 做 `SessionScopedToolRegistry` 装饰器）。
