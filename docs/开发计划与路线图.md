# 开发计划与路线图

[← 文档索引](文档索引.md) · [仓库首页](../README.md)

---

本文档为**唯一整体路线**：章节按 **1 → 2 → 3 → …** 编号，开发时**按顺序推进**即可。同一节内子项可并行，但**默认完成当前节再进入下一节**；若需插队，在 PR/说明里注明依赖关系。

---

## 1. 核心框架与配置存储

- [x] 基础架构搭建
- [x] 服务端-客户端分离
- [x] REST API 接口
- [x] 配置管理（统一加载、热更新策略）
- [x] 本地存储与会话/消息持久化骨架
- [x] SQLite schema 版本化迁移（Flyway / Liquibase）与发布流程对齐

## 2. LLM 与会话核心

- [x] LLM 集成（DashScope 等）
- [x] 会话管理（`session_id`、多会话并发）
- [x] 消息路由与上下文管线
- [x] 流式与非流式输出

## 3. Tool / Skill 与 Capability Registry

- [x] 内置 Tool 与执行沙箱
- [x] Skill 编排与执行
- [x] **Capability Registry** 落地：Tool / Skill / MCP tool / Plugin 统一发现与调用语义

## 4. 知识库与多模态

- [x] 向量检索与 RAG 流水线
- [x] 多模态处理（文本 / 图片 / 文档）
- [x] RAG 输出**来源标注**（`citations[]`，便于核对）

## 5. MCP 集成

- [ ] MCP Client（连接、重试、退避）
- [ ] 与 Registry 对接，工具与资源发现
- [ ] （进阶）MCP 资源订阅与缓存失效策略

## 6. 插件系统

- [ ] 插件加载与生命周期
- [ ] ClassLoader 隔离与沙箱（资源/超时）
- [ ] 插件依赖管理

## 7. A2A 协作

- [ ] Agent 注册与发现、生命周期
- [ ] Agent 间消息路由
- [ ] 协作模式：主从、对等、任务流、投票
- [ ] `a2a_session_id` 协作会话管理

## 8. 编排、观测与背压

- [ ] **Orchestrator**（任务分解、DAG、人机确认节点）
- [ ] **Request Gate**：请求队列与并发上限（按 session / 用户）
- [ ] **结构化 Trace**（`session_id`、`agent_id`、`tool_call_id`、latency、token 等）
- [ ] 上下文压缩与裁剪策略落地（与会话模块联动）

## 9. 契约与多端

- [ ] OpenAPI 与领域模型 / `common` DTO 同源演进
- [ ] gRPC（可选）与 REST 语义对齐
- [ ] Web UI（可选）

## 10. 可靠性与任务治理

- [ ] LLM / MCP **重试、降级、熔断**与备用端点
- [ ] **幂等与去重**（消息与 tool 调用）
- [ ] 长任务 / A2A 工作流**检查点与恢复**
- [ ] **定时与后台任务**（本地 scheduler 或系统 cron 触发）

## 11. 安全、审计与策略

- [ ] 安全加固（与 [安全配置与数据持久化](安全配置与数据持久化.md) 拓展一致）
- [ ] **审计日志**（工具调用、路径访问，与 Trace 关联）
- [ ] **策略引擎**：按会话 / Agent 限制工具列表与出站网络

## 12. 交互与体验

- [ ] 多轮澄清与目标确认（Orchestrator 前置）
- [ ] **Human-in-the-loop**（敏感操作前批准；「仅本次」等粒度）
- [ ] 长期记忆与偏好（隐私最小化、可清除/可导出）
- [ ] 语音 / 多模态 I/O（ASR/TTS 可选通道）

## 13. A2A+ 与知识增强

- [ ] 角色模板与动态组队
- [ ] 辩论 / 红队模式（与投票互补）
- [ ] 共享**黑板**（结构化中间结果）
- [ ] **混合检索**（关键词 + 向量 + 元数据；范围如「仅本仓库」）
- [ ] 文档与代码**增量索引**与失效策略

## 14. 开发者体验

- [ ] Agent / Skill **声明式 YAML** 热更新与 JSON Schema 校验
- [ ] 本地**调试模式**（单步 tool、会话录制回放）
- [ ] **评测与回归**（固定数据集、CI 可选门禁）

## 15. 生产就绪

- [ ] 性能优化与容量基线
- [ ] **集成测试矩阵**（单 Agent、Tool、MCP 失败重试、A2A 两跳）
- [ ] 文档与示例完善
- [ ] 用量统计（可选）

## 16. 可选扩展（依赖需求再开）

- [ ] 远程访问：TLS、Token 轮换（与架构「安全与远程访问」拓展一致）
- [ ] 其他产品化项按 Issue 驱动
