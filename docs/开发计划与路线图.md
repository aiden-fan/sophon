# 开发计划与路线图

[← 文档索引](文档索引.md) · [仓库首页](../README.md)

---

本文档为**唯一整体路线**：章节按 **1 → 2 → 3 → …** 编号，开发时**按顺序推进**即可。同一节内子项可并行，但**默认完成当前节再进入下一节**；若需插队，在 PR/说明里注明依赖关系。

---

## 1. 核心框架与配置存储

- [ ] 基础架构搭建
- [ ] 服务端-客户端分离
- [ ] REST API 接口
- [ ] 配置管理（统一加载、热更新策略）
- [ ] 本地存储与会话/消息持久化骨架；**Spring `api/persistence`**：`SessionRepository` / `SessionPersistenceService`，**消息体以 `Unified*` 规范 JSON 落库**（`schema_version`），与 §2 一致，**不**存厂商原生结构
- [ ] SQLite schema 版本化迁移（Flyway / Liquibase）与发布流程对齐

## 2. LLM 与会话核心

- [ ] LLM 集成（DashScope 等）
- [ ] **`core.llm.unified` 统一模型**：`UnifiedMessage` / `UnifiedContentPart` / `UnifiedStreamEvent`（**tagged union** 扩展）；**Engine / Session / RAG 注入 / Tool 结果并线 / Orchestrator（LLM 相关）** 只传递 `Unified*`；**各 Provider `LLMClient` 唯一** 负责统一 ⇄ 厂商映射，**禁止**对外 API 与**禁止**在非 Provider 路径持久化厂商 JSON
- [ ] **会话内切换 `provider`/`model`**：每次调用按 `SessionConfig` 选 Client；历史消息以统一模型持久化，换模后不适配内容在 core 内报错或策略降级
- [ ] 会话管理（`session_id`、多会话并发）
- [ ] **会话独占连接**：同一 `session_id` 任意时刻仅 **一个活跃控制连接**；新连策略可配置（**拒绝** / **抢占并断开旧连接** / 需先 **release**）
- [ ] 连接与会话绑定模型（鉴权 token、`session_id` lease、断线清理与指标）
- [ ] 消息路由与上下文管线
- [ ] 流式与非流式输出
- [ ] **流式落库策略**落地：用户消息先行提交 vs 合并提交；assistant 在 **`done`** 后短事务追加；断线/`error` 与 **incomplete** 策略（见 [架构设计](架构设计.md)「流式响应与持久化策略」）
- [ ] **`AgentInstance` 进程内缓存**（Caffeine 等）：键含 `session_id` + 绑定/配置摘要；绑定与配置变更 **invalidate**（见 [架构设计](架构设计.md)「Agent 实例缓存与再组装策略」）
- [ ] **用户对话路径**：**加载会话**（Spring 持久化）→ **`core` 组装 `AgentInstance` + `AgentEngine`** → **Spring 写回增量**；可选 `ConversationApplicationService` 薄编排（见 [架构设计](架构设计.md)）
- [ ] **会话级 Agent 绑定 API**（Spring：`SessionAgentBindingController` + **落库**）：**core** `SessionAgentBindingService` 校验与合并 + `AgentFactory` 语义；成功后 **Spring** `SessionPersistenceService` 持久化绑定快照（见 [架构设计](架构设计.md)）

## 3. Tool / Skill 与 Capability Registry

- [ ] 内置 Tool 与执行沙箱
- [ ] Skill 编排与执行
- [ ] **Capability Registry** 落地：Tool / Skill / MCP tool / Plugin 统一发现与调用语义
- [ ] **Agent 能力抽象**：`AgentCapability`（或与 Registry `Capability` 同构）作为 Tool / Skill / RAG 等在组装层的统一注入边界
- [ ] **AgentFactory / AgentAssembler** 与 **AgentInstance**：从配置（YAML 等）+ Registry **解析启用能力 id**，组装运行态 Agent；**AgentEngine 只依赖组装结果**，不在调用链上散落 new 各子系统
- [ ] 组装路径初版可先接入**进程内** Tool / Skill；**MCP 在 §5 完成后接入同一组装路径**（见下节衔接项）

## 4. 知识库与多模态

- [ ] 向量检索与 RAG 流水线
- [ ] 多模态处理（文本 / 图片 / 文档）：**输入/输出**均纳入 **统一 `parts[]`**；各模型适配器将 `image`/`audio`/文档引用等映射到厂商字段
- [ ] **聊天 HTTP 响应与 SSE**：非流式返回 `output.parts[]`；流式推送 **统一事件类型**（与架构设计一致），与 §2 `UnifiedStreamEvent` 同源
- [ ] RAG 输出**来源标注**（`citations[]`，便于核对）

## 5. MCP 集成

- [ ] MCP Client（连接、重试、退避）
- [ ] 与 Registry 对接，工具与资源发现
- [ ] **MCP → 统一 Capability / Tool 适配**，使 MCP 暴露的能力纳入 **§3 AgentFactory** 的组装路径（与内置 Tool 并列）
- [ ] （进阶）MCP 资源订阅与缓存失效策略

## 6. 插件系统

- [ ] 插件加载与生命周期
- [ ] ClassLoader 隔离与沙箱（资源/超时）
- [ ] 插件依赖管理

## 7. A2A 协作

- [ ] Agent 注册与发现、生命周期
- [ ] Agent 间消息路由
- [ ] 协作模式：主从、对等、任务流、投票
- [ ] `a2a_session_id` 协作会话管理

## 8. 编排、观测与背压

- [ ] **Orchestrator**（任务分解、DAG、人机确认节点）
- [ ] **Request Gate**：**仅** `api.gate` **Spring Bean**（队列、并发、限流）；**不实现在 `core.*`**；准入后再进入「加载会话 → core」（见 [架构设计](架构设计.md)「背压与请求门控」）
- [ ] **结构化 Trace**（`session_id`、`agent_id`、`tool_call_id`、latency、token 等）
- [ ] 上下文压缩与裁剪策略落地（与会话模块联动）

## 9. 契约与多端

- [ ] OpenAPI 与领域模型 / `common` DTO 同源演进
- [ ] gRPC（可选）与 REST 语义对齐
- [ ] **Spring 限定在接口层**：WebFlux/Boot 仅管理 `api.*`（Controller、Filter、DTO、SSE 适配）；领域逻辑经**窄门面**调用 `core.*`，避免 Controller 内手写 Agent 组装细节；**会话绑定类配置接口**仍属 `api.*`，仅委托 core
- [ ] Web UI（可选）

## 10. 可靠性与任务治理

- [ ] LLM / MCP **重试、降级、熔断**与备用端点
- [ ] **幂等与去重**（消息与 tool 调用）
- [ ] 长任务 / A2A 工作流**检查点与恢复**
- [ ] **定时与后台任务**（本地 scheduler 或系统 cron 触发）

## 11. 安全、审计与策略

- [ ] 安全加固（与 [安全配置与数据持久化](安全配置与数据持久化.md) 拓展一致）
- [ ] **审计日志**（工具调用、路径访问，与 Trace 关联）
- [ ] **策略引擎**：按会话 / Agent 限制工具列表与出站网络

## 12. 交互与体验

- [ ] 多轮澄清与目标确认（Orchestrator 前置）
- [ ] **Human-in-the-loop**（敏感操作前批准；「仅本次」等粒度）
- [ ] 长期记忆与偏好（隐私最小化、可清除/可导出）
- [ ] 语音 / 多模态 I/O（ASR/TTS 可选通道）

## 13. A2A+ 与知识增强

- [ ] 角色模板与动态组队
- [ ] 辩论 / 红队模式（与投票互补）
- [ ] 共享**黑板**（结构化中间结果）
- [ ] **混合检索**（关键词 + 向量 + 元数据；范围如「仅本仓库」）
- [ ] 文档与代码**增量索引**与失效策略

## 14. 开发者体验

- [ ] Agent / Skill **声明式 YAML** 热更新与 JSON Schema 校验
- [ ] 本地**调试模式**（单步 tool、会话录制回放）
- [ ] **评测与回归**（固定数据集、CI 可选门禁）

## 15. 生产就绪

- [ ] 性能优化与容量基线
- [ ] **集成测试矩阵**（单 Agent、Tool、MCP 失败重试、A2A 两跳）
- [ ] 文档与示例完善
- [ ] 用量统计（可选）

## 16. 可选扩展（依赖需求再开）

- [ ] 远程访问：TLS、Token 轮换（与架构「安全与远程访问」拓展一致）
- [ ] 其他产品化项按 Issue 驱动
