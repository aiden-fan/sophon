# 产品能力规格（正文需求）

与 [架构说明](架构.md)、[交付阶段](交付阶段.md) 一致；实现时以 `core/application` 与既有分层落地，**不得**仅在 `cli` 包实现业务编排。

<a id="toc-spec"></a>

## 对话与模型

| 能力        | 要求                                                                                        |
| --------- | ----------------------------------------------------------------------------------------- |
| **流式输出**  | `AIProvider` 提供流式生成能力；CLI 与 Web **SSE/WebSocket** 消费同一 application 用例，边生成边展示。 |
| **上下文管理** | `ConversationManager` 支持可配置的**滑动窗口**与/或**自动摘要**，超出模型窗口时不得静默截断而不留痕迹（摘要写入元数据或约定消息角色需实现一致）。  |
| **编辑后重答** | 支持从指定用户消息起**重新生成**；可选**分支会话**保留原历史。                                                       |
| **降级**    | 主模型失败时：可配置回退**备用模型**，或降级为仅 RAG / 仅规则回复（**会话级或全局**开关）。                                     |
| **用量统计**  | 按**会话**、按**模型**记录 **token**（及可选费用估算），供展示与异常排查。                                            |

## RAG 与知识

| 能力         | 要求                                                                                                                                 |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **可解释与引用** | RAG 回答须能附带**引用列表**（片段、文档名、chunk id 等）；`SessionCapabilityConfig` 或等价字段支持 **citations 开关**；`/citations on` / `/citations off` 与会话绑定。 |
| **检索范围**   | 仅使用**当前会话已绑定**知识库（见 [会话与命令](会话命令.md)）。                                                                                                       |

## Tool、Skill 与会话安全

| 能力        | 要求                                                                                        |
| --------- | ----------------------------------------------------------------------------------------- |
| **高危确认**  | 写文件、删改、对外副作用类 Tool：`ToolDefinition` 声明 **风险等级**；执行前**用户确认**或仅当会话为**高信任**配置时允许自动执行（策略可配置）。 |
| **审计**    | **Tool/MCP 调用**写入审计记录：会话 id、工具 id、参数摘要、结果状态、时间；与业务日志区分，便于复盘。                              |
| **会话级速率** | 在全局限制之外，支持**单会话**对 Tool/MCP 调用频率上限。                                                       |
| **兼容与校验** | `skill.yaml` 等声明 `minSophonVersion`、依赖 Tool 版本范围；加载时校验，错误须可读。                             |

## 会话与数据生命周期

| 能力          | 要求                                                                                        |
| ----------- | ----------------------------------------------------------------------------------------- |
| **Profile** | **命名预设**（如 `coding`、`写作`）对应一组 `SessionCapabilityConfig` 快照；`/profile` 或等价命令与应用层 API 应用预设。 |
| **导出/导入**   | 会话消息与元数据支持 **Markdown/JSON** 导出与导入，便于备份与迁移。                                               |
| **分叉**      | 从当前会话复制配置与近期上下文**新建会话**，便于对比实验。                                                           |
| **跨会话搜索**   | 对历史消息建立**本地索引**，支持关键词检索（隐私与存储策略在实现中说明）。                                                   |

## CLI 与 Web

| 能力          | 要求                                                        |
| ----------- | --------------------------------------------------------- |
| `/` 命令      | 除能力开关外，包含 `/doctor`（或等价名）自检：API Key、MCP、向量库、注册 Tool 数量等。  |
| **输入体验**    | CLI 宜支持行编辑与**命令历史**（如基于 JLine）。                           |
| **Web API** | 与会话能力、聊天、流式输出 **同构**；支持向指定知识库 **上传文档**（权限、配额、安全扫描在实现层约束）。 |

## 质量与工程

| 能力       | 要求                                                                     |
| -------- | ---------------------------------------------------------------------- |
| **批测回归** | 提供对 Skill/系统提示的**固定数据集批跑**能力，用于变更前后对比。                                 |
| **国际化**  | 用户可见 CLI/错误信息支持多语言（资源文件或等价机制）。                                         |
| **多模态**  | 在模型与提供商支持前提下，扩展图像等输入/输出（接口预留）。                                         |
| **定时任务** | 定时触发指定 Skill：独立调度进程或内置调度器、**资源隔离**与**安全策略**须单独成章或配置（实现可晚于核心对话，但属正文规格）。 |
