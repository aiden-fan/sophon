## 常见问题

### Q: 服务端必须先启动吗？
A: 是的，CLI 需要连接到服务端才能工作。CLI 会自动检测服务端是否运行，如果没有会提示启动。

### Q: 能否同时运行多个 CLI 客户端？
A: 可以，服务端支持多个客户端同时连接和会话。

### Q: 服务端崩溃了会丢失数据吗？
A: 会话数据持久化到本地数据库，服务端重启后可以恢复。未持久化的消息可能会丢失。

### Q: 如何切换 LLM Provider？
A: 通过 API 或 CLI 修改会话配置：
```bash
# 切换到 DashScope
sophon> session config --set llm.provider=dashscope --set llm.model=qwen-max

# 切换到 OpenAI
sophon> session config --set llm.provider=openai --set llm.model=gpt-4

# 切换到 Claude
sophon> session config --set llm.provider=claude --set llm.model=claude-3-5-sonnet-20241022
```

### Q: 如何添加自定义 Tool？
A: 实现 Tool 接口，打包成 JAR，通过 API 加载插件。

### Q: 支持远程访问吗？
A: 默认只监听本地 127.0.0.1，可以在配置中修改 host 和 allowed_clients 来支持远程访问（需注意安全）。

### Q: 如何创建多个 Agent？
A: 在 `~/.sophon/config/agents/` 目录下创建 Agent 配置文件，然后使用命令注册：
```bash
sophon> agent register --id coding_agent --config ~/.sophon/config/agents/coding_agent.yaml
```

### Q: 如何让多个 Agent 协作？
A: 创建 A2A 协作会话，指定参与的 Agent 和协作模式：
```bash
sophon> a2a create \
  --name "代码分析协作" \
  --agents coding_agent,review_agent,test_agent \
  --mode taskflow
```

### Q: 支持哪些协作模式？
A: 支持 4 种协作模式：
- **Master-Slave (主从)**: 一个主 Agent 控制多个子 Agent
- **Peer-to-Peer (对等)**: 多个 Agent 平等协作
- **Task Flow (任务流)**: 按 DAG 流程执行 Agent 链
- **Voting (投票)**: 多 Agent 协商决策

### Q: 可以自定义协作工作流吗？
A: 可以，使用 `--workflow` 参数或在工作流文件中定义 DAG 流程：
```yaml
workflow:
  - step: "分析"
    agent: "analyzer"
  - step: "审查"
    agent: "reviewer"
    depends_on: "分析"
  - step: "测试"
    agent: "tester"
    depends_on: "审查"
```

### Q: 如何监控 Agent 协作状态？
A: 使用 `a2a status` 命令查看协作会话的实时状态：
```bash
sophon> a2a status --session a2a_001
```
