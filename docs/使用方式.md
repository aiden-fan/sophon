# 使用方式（CLI 与服务端）

[← 文档索引](文档索引.md) · [仓库首页](../README.md)

---

最简命令见仓库 **[README](../README.md#quick-start)**；以下为分步说明与完整示例。

### 1. 启动服务端

```bash
# 方式1: 使用脚本
./scripts/start-server.sh

# 方式2: 使用 Maven
cd server
mvn exec:java -Dexec.mainClass="com.sophon.server.ServerApp"

# 方式3: 使用打包后的 JAR
java -jar server/target/sophon-server-1.0.0.jar

# 后台运行
nohup java -jar server/target/sophon-server-1.0.0.jar > /dev/null 2>&1 &
```

服务端启动后会：
- 监听本地端口（默认 8080）
- 加载配置和插件
- 初始化数据库和缓存
- 输出进程 ID 到 `~/.sophon/data/server.pid`

### 2. 启动 CLI 客户端

```bash
# 方式1: 使用脚本
./scripts/start-cli.sh

# 方式2: 使用 Maven
cd client/cli
mvn exec:java -Dexec.mainClass="com.sophon.client.cli.CliApp"

# 方式3: 使用打包后的 JAR
java -jar client/cli/target/sophon-cli-1.0.0.jar
```

### 3. 交互使用

```bash
# 进入交互模式
sophon>

# 创建会话
sophon> session create --name "我的助手"

# 切换会话
sophon> session switch --id session_001

# 发送消息（非流式）
sophon> chat "帮我分析这段代码"

# 流式输出
sophon> chat --stream "生成一个排序算法"

# 查看历史
sophon> history

# 查看统计
sophon> stats --session session_001

# 管理插件
sophon> plugin list
sophon> plugin load ~/.sophon/plugins/my-plugin.jar
sophon> plugin unload my-plugin

# A2A 相关命令
# 列出所有 Agent
sophon> agent list

# 注册新 Agent
sophon> agent register --id coding_agent --config ~/.sophon/config/agents/coding_agent.yaml

# 创建协作会话
sophon> a2a create --name "代码协作会话" --agents coding_agent,review_agent,test_agent --mode taskflow

# 向协作会话发送任务
sophon> a2a task --session a2a_001 --task "分析这段代码并生成测试用例"

# 查看协作状态
sophon> a2a status --session a2a_001

# 退出
sophon> exit
```

### 4. 停止服务端

```bash
# 方式1: 使用脚本
./scripts/stop-server.sh

# 方式2: 手动停止
kill $(cat ~/.sophon/data/server.pid)
```
