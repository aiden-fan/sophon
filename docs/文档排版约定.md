# 文档排版约定（维护用）

- **标题层级**：`#` 仅用于文档主标题；`##` 主章节；`###` 小节；避免跳级（如 `##` 后直接 `####`）。
- **表格**：GFM 管道表；表头下需有分隔行；单元格内换行用 `<br>` 或拆行。
- **代码围栏**：成对出现，并标注语言（`bash`、`yaml`、`java` 等）；嵌套 Markdown 示例时，内层长示例用**缩进 4 空格**或避免在未转义的内层 `` ``` `` 中破坏外层围栏。
- **强调与行内代码**：类型名、API 名用行内代码 `` `LikeThis` ``；避免反引号与星号交叉嵌套导致表格错乱。
- **锚点**：易歧义或含特殊字符的标题，在标题前使用 `<a id="toc-…"></a>`，与目录链接一致。
- **横线**：主章节之间可用 `---` 分隔（可选）；全文风格保持一致。
