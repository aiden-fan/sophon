## Quick Start

### 环境要求

| 组件 | 版本要求 | 何时需要 |
|------|----------|----------|
| **JDK** | **17** 或 **21**（LTS） | **必需**。与 `pom.xml` 中 `maven.compiler` 一致。 |
| **Maven** | **3.8.1+**（推荐 **3.9.x**） | **必需**。 |
| **Node.js** | **18.x+** 或 **20.x+**（LTS） | **可选**。MCP 通过 **`npx`** 启动 stdio 服务端时需要。 |
| **npm** / **npx** | 随 Node 自带 | 与上项相同。 |
| **Git** | 近期版本 | 协作时建议。 |

**自检：**

```bash
java -version    # 应显示 17 或 21
mvn -version     # 应显示 Maven 3.8+
node -v          # 若使用 MCP
```

<a id="toc-common-commands"></a>

### 常用命令

#### 构建

```bash
mvn clean compile
```

#### 运行

**默认：仅启动 Web（Spring WebFlux）**，终端不再进入交互；需 **`DASHSCOPE_API_KEY`**（见 [配置 — AI](配置说明.md#toc-ai-dashscope)）。默认端口见 `application-web.yml`。

```bash
mvn exec:java
```

放后台示例：`nohup mvn exec:java > sophon.log 2>&1 &`

**交互 CLI**（另开进程，与 Web **共用同一 SQLite**；适合在终端里对话）：

```bash
./scripts/sophon
# 或
mvn exec:java -Dexec.args="--cli"
```

CLI 下指定 **system 提示**（仍可在交互里用 `/prompt` 按会话修改）：

```bash
mvn exec:java -Dexec.args="--cli --system-prompt 你是简洁的技术助手"
```

写库冒烟（不调用模型）：

```bash
mvn exec:java -Dexec.args="--smoke"
```

**显式 `--web`**（与无参数等价，兼容旧命令）：

```bash
mvn exec:java -Dexec.args="--web"
```

**批测回归**（`--batch-tests`，退出码 0 表示通过）：

```bash
mvn exec:java -Dexec.args="--batch-tests"
```

CLI **中文**可设 `SOPHON_LANG=zh`。

**打包运行**（依赖在 `target/lib/`，见 [技术栈 — Maven](技术栈.md#toc-maven-deps)）：

```bash
mvn clean package
java -jar target/sophon-0.1.0-alpha-SNAPSHOT.jar
java -jar target/sophon-0.1.0-alpha-SNAPSHOT.jar --cli
java -jar target/sophon-0.1.0-alpha-SNAPSHOT.jar --smoke
java -jar target/sophon-0.1.0-alpha-SNAPSHOT.jar --web
```

打包后也可用环境变量 **`SOPHON_JAR=target/sophon-….jar ./scripts/sophon`** 呼出 CLI。

#### 测试

```bash
mvn test
mvn test -Dtest=ClassName
mvn clean
mvn install
```

## 开发指南（其它主题）

**Tool、Skill、知识库、MCP、RAG 流程与目录规范**见 [知识库与 RAG 协作](知识库与RAG协作.md)。

### 切换数据库

1. 实现 `StorageAdapter` 接口
2. 在 `storage/` 包下新增实现
3. 在 `ConfigManager` 中配置适配器
4. 规划 SQLite 数据迁移

### 扩展到 Web 界面

1. HTTP 适配层**仅**做参数绑定、鉴权、序列化
2. **业务编排**调用 `core/application` 用例，与 CLI **共用** API（流式 SSE、会话能力、导出、用量、自检、上传入 KB 等）
3. 前端资源可置于 `src/main/resources/web/`

### 添加新的 AI 模型提供商

1. 实现 `AIProvider` 接口
2. 在 `ai/` 包下创建 Provider 类
3. 在 `ModelSelector` 中注册
4. 更新 `application.yml`

## 项目结构

<a id="toc-resource-mapping"></a>

### 资源目录与 Java 包对应关系

| 资源路径（`src/main/resources/`） | 说明 | 与代码的对应关系 |
|-----------------------------------|------|------------------|
| `application.yml` | 应用主配置 | `config.ConfigManager` / `AppConfig` |
| `skills/<skill-id>/` | **内置**技能（每目录 `SKILL.md`，可选 `skill.yaml`） | `skill.SkillLoader.loadSkillMdResource` |
| `tools/local/`、`tools/mcp/` | 工具侧配置片段 | `tool.ToolManager` / MCP 启动配置 |
| `knowledge/docs/`、`knowledge/config/` | 文档与样例 | `KnowledgeManager` 默认路径等 |
| `db/` | SQLite 脚本或迁移 | `storage` 初始化 |

用户目录（`~/.sophon/skills/` 等）由运行时解析，**不**映射到 `src/main/resources`。

```
src/
├── main/
│   ├── java/com/sophon/
│   │   ├── Sophon.java
│   │   ├── core/
│   │   ├── model/
│   │   ├── storage/
│   │   ├── knowledge/
│   │   ├── tool/
│   │   ├── skill/
│   │   ├── ai/
│   │   ├── cli/
│   │   ├── web/
│   │   └── config/
│   └── resources/
│       ├── application.yml
│       ├── skills/            # 例：greet/SKILL.md、markdown_doc/SKILL.md
│       ├── tools/
│       ├── knowledge/
│       └── db/
└── test/java/com/sophon/
```

### 测试目录约定

| 项 | 约定 |
|----|------|
| **路径** | `src/test/java/com/sophon/`，与 `main` **包前缀一致**。 |
| **分层** | 单元测试贴近被测包；集成测试可用 `…integration` 子包或 `*IT` 后缀，与 CI profile 对应。 |

## 开发注意事项

1. **接口优先**：新功能先定义接口再实现
2. **配置驱动**：行为尽量走配置，避免硬编码
3. **错误处理**：统一异常与用户可见提示
4. **日志**：SLF4J，级别合理；敏感信息脱敏
5. **测试**：核心逻辑单测 + 必要集成测
6. **Tool**：单一职责、可测试；高危与审计见 [产品规格](产品规格.md)
7. **Skill**：面向场景；执行前校验**当前会话**是否启用所需 Tool / 知识库
8. **性能**：MCP 子进程成本、向量检索、分块大小
9. **安全**：沙箱、会话信任、审计与限流、用户技能目录分级
10. **可靠性**：超时/重试与 [配置 — 失败与重试](配置说明.md#toc-resilience)、降级与用量统计一致
11. **国际化**：用户可见字符串走资源文件
12. **可观测**：trace id 关联请求与 Tool 调用
13. **质量**：批测回归入口；`SKILL.md` frontmatter / `skill.yaml` 中 `minSophonVersion` 等校验

## 扩展点

1. **存储**：`StorageAdapter`
2. **AI**：`AIProvider`
3. **界面**：`CLIController` / Web 控制器 → 仅调 `core/application`
4. **Skill**：目录 + `SKILL.md`（YAML frontmatter）；`SkillLoader` 可扩展（仍支持独立 `skill.yaml`）
5. **Skill 实现类型**：首版 Java + 一种脚本协议；其它语言标为后续
6. **Tool**：`LocalTool`、`MCPTool`、`ToolExecutor`
7. **MCP**：协议与自定义服务端
8. **配置**：`ConfigManager` 自定义加载器
9. **知识库**：`VectorStore`、`EmbeddingProvider`、`DocumentParser`
10. **会话能力**：`SessionCapabilityConfig` + Registry 会话级过滤；`SlashCommandRouter` 子命令可插拔
11. **流式**：`AIProvider` 以 Reactor `Flux` 为流式 API（见 [技术栈](技术栈.md)）
12. **审计与用量**：`ToolAuditLogger`、`UsageTracker` 可替换实现
13. **会话数据**：导出/导入、分叉、跨会话搜索策略可插拔
14. **可观测**：OpenTelemetry（可选）
