# 项目目录结构

## 文件结构

```
~/novels/项目名/
├── novel.yaml              # 项目元信息（标题、类型、描述、风格）
├── world-setting.md        # 世界观设定（修炼体系、地理、势力）
├── outline.md              # 总大纲（简介、主线、章节规划）
├── prompts/                # 自定义 prompt 模板（可选，可修改）
│   ├── character-base.md   # 角色生成 prompt
│   ├── outline-base.md     # 大纲生成 prompt
│   └── write-base.md       # 章节写作 prompt
├── characters/             # 角色档案（.md 文件）
│   └── 张三.md
├── outlines/               # 章节大纲（.md 文件）
│   └── chapter-001.md
└── chapters/               # 章节正文（.txt 文件，纯文本）
    └── chapter-001-穿越.txt
```

## 文件格式说明

### novel.yaml

项目元数据，YAML frontmatter 格式：

```yaml
---
title: 项目名称
genre: 类型（如 修仙、玄幻、都市）
description: 项目描述
style: 风格
created: 2026-04-20
---
```

### world-setting.md

世界观设定，包含 YAML frontmatter：

```markdown
---
genre: 类型
---
# 世界观设定

## 修炼体系


## 地理


## 势力

```

### outline.md

总大纲，包含 YAML frontmatter：

```markdown
---
total_chapters: 总章节数
current_chapter: 当前章节
---
# 项目名称

## 简介


## 主线


## 章节规划
### 第一卷

```

### characters/*.md

角色档案，包含 YAML frontmatter：

```markdown
---
name: 角色名
role: 角色定位（protagonist/antagonist/supporting）
status: alive
---
# 角色名

## 外貌


## 性格


## 修为/能力


## 背景


## 人际关系

```

### outlines/chapter-NNN.md

章节大纲，包含 YAML frontmatter：

```markdown
---
chapter: 章节编号
title: 章节标题
word_count_target: 预计字数
key_characters: [出场角色]
---
# 第X章 章节标题

## 本章要点
（核心事件）

## 场景一：场景名称
- 地点：
- 出场人物：
- 情节：
- 伏笔/铺垫：

## 本章伏笔与悬念

## 与前后章节的衔接

```

### chapters/chapter-NNN-标题.txt

章节正文，纯文本格式，不含 Markdown 语法：

```txt
---
chapter: 1
title: 穿越
word_count: 3500
---

正文内容...
```

## 自定义 Prompt

`prompts/` 目录下的文件用于自定义 AI 生成 prompt。如果项目 `prompts/` 目录下存在对应文件，则优先使用；否则使用内置默认。

支持的关键词替换（在 prompt 中使用 `${...}`）：

| 关键词 | 替换内容 |
|--------|----------|
| `${world_setting}` | world-setting.md 正文 |
| `${outline}` | outline.md 正文 |
| `${characters}` | 所有角色文档正文拼接 |
| `${novel_info}` | novel.yaml 内容 |
| `${outline_chapter_N}` | 指定章节大纲 |
| `${chapter_N}` | 指定章节正文 |

## 新增自定义文件类型

如需新增文件类型（如"势力设定"、"地图描述"等）：

1. 在 `NovelProjectPath.java` 中添加路径方法和扫描逻辑
2. 在 `docType()` 中注册新类型
3. 在 `PromptRenderer.java` 中添加新的 `${}` 关键词
4. 在 `DefaultContextBuilder.java` 的 `TYPE_ORDER` 中添加排序权重
5. 更新对应的 base prompt 模板引用新关键词
