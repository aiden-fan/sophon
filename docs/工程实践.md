### 契约优先（Contract-first）

- **REST**：以 **OpenAPI** 描述 HTTP API；服务端实现、客户端 SDK 与 `common` 模块中的领域模型/DTO **同源演进**，避免 `server` 与 `client` 各自为政。
- **gRPC（若启用）**：`.proto` 与 REST 资源在语义上对齐或有明确映射表，IDL 与领域模型**同步评审、同步发版**。
- **收益**：减少联调漂移，CLI/Web 与 A2A 共用同一套契约生成或校验逻辑（可选）。

### 集成测试矩阵（最低集）

| 场景 | 目的 |
|------|------|
| 单 Agent 对话 | 会话、聊天、上下文基础路径 |
| Tool 调用 | `Capability Registry` → 内置或 Plugin 工具执行全链路 |
| MCP 连接失败与重试 | 模拟 MCP 不可用/超时，验证退避、错误封装与恢复 |
| A2A 两跳任务流 | 至少两个 Agent 顺序协作，编排状态与 **trace** 可核对 |

以上四类作为集成测试与 CI 的**架构基线**；首版可部分以手动/半自动验收，但接口与模块划分应预留自动化挂载点。
